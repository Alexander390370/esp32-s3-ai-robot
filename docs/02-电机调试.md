## 要焊 10 个点

### 左侧（信号 + 电源）6 个

| 焊盘 | 焊什么线 | 接到 ESP32 |
|---|---|---|
| `+` | 杜邦线 | 面包板 5V 轨 |
| `−` | 杜邦线 | 面包板 GND 轨 |
| INT1 | 杜邦线 | GPIO6 |
| INT2 | 杜邦线 | GPIO7 |
| INT3 | 杜邦线 | GPIO15 |
| INT4 | 杜邦线 | GPIO16 |

### 右侧（电机）4 个

| 焊盘 | 焊什么线 |
|---|---|
| MOTOR-A 上孔 | 左电机红线 |
| MOTOR-A 下孔 | 左电机黑线 |
| MOTOR-B 上孔 | 右电机红线 |
| MOTOR-B 下孔 | 右电机黑线 |

**左右怎么分**：人站在车后面朝前看，左手边是左轮。

## 焊接步骤

### 准备

```
1. 电烙铁预热到 350°C
2. 准备焊锡丝、助焊剂（可选）
3. 剪 6 根杜邦线，一端剥 3mm 铜丝
4. 电机线末端剥 3mm
```

### 每个点的焊法（20 秒一个）

```
第 1 步：铜丝穿进焊盘孔（从背面穿到正面）

第 2 步：烙铁头同时接触「焊盘铜环」和「铜丝」
         停留 1.5-2 秒（让焊盘预热）

第 3 步：焊锡丝碰上去，熔一小坨（米粒大小）
         不要堆成球

第 4 步：先撤焊锡丝，再撤烙铁

第 5 步：保持不动 1 秒，让焊点自然凝固
```

**关键**：烙铁要同时接触焊盘和线，不能只碰线。

### 焊接顺序

```
1. 先焊 + 和 −（电源，最重要）
2. 再焊 INT1-4（信号）
3. 最后焊电机线（MOTOR-A/B）
```

**为什么先焊电源**：如果电源虚焊，后面的测试全部白费。

---

## 焊完必须检查

### 1. 目视检查

```
□ 每个焊点都是亮的圆锥形（发暗/毛糙 = 虚焊）
□ 没有两个焊点连在一起（短路）
□ 铜丝没有翘出来碰到别处
```

### 2. 万用表测（断电）

```
把万用表打到 Ω 的 2000 档

□ 测 + 和 − 之间：> 100Ω（不能是 0）
□ 测 INT1 和 INT2 之间：不通（显示 1 或 OL）
□ 测 INT2 和 INT3 之间：不通
□ 测 INT3 和 INT4 之间：不通
□ 测 MOTOR-A 两个孔之间：几十欧（电机线圈）
□ 测 MOTOR-B 两个孔之间：几十欧
```

**如果测出来 0**：短路，用吸锡带吸掉重焊。

### 3. 虚焊怎么判断

```
好的焊点：表面光亮、圆锥状、边缘平滑
虚焊：   表面粗糙、发暗、球状、能晃动
```

**虚焊的表现**：轮子时转时不转、一碰线就停。

## 常见问题

### 焊锡不沾

```
原因：焊盘氧化 / 温度不够 / 没助焊剂
解决：
  1. 烙铁温度调到 380°C
  2. 用砂纸或橡皮擦一下焊盘
  3. 涂一点助焊剂
```

### 两个焊点连在一起

```
原因：焊锡太多
解决：
  1. 用吸锡带（或细铜丝）吸掉多余焊锡
  2. 重新焊，这次少放焊锡
```

### 电机线太粗焊不上

```
原因：电机线是 26AWG，比焊盘孔粗
解决：
  1. 只剥 2mm，不要剥太长
  2. 铜丝拧紧成一股再穿
  3. 或者剪一小段细线转接
```

### 焊完轮子不转

```
排查顺序：
  1. 万用表测 INT1-4 有没有信号（点方向键时电压变化）
  2. 测 MOTOR-A/B 有没有输出（几伏）
  3. 检查 MX1508 的 + 和 − 有没有接触好
  4. 检查电机线焊点有没有虚焊
```

---

## 焊完之后

```
1. 插到面包板上
2. 接好 INT1-4 + 电源
3. 接好电机
4. 复位板子
5. 看串口：[避障] 前方 Xcm，转向
6. 轮子应该转
```

**某个轮子反了**：把那两根电机线对调（不用改代码）。

**都不转**：检查 MX1508 的电源，或者测 INT 引脚有没有信号。

## 二、方向校准

### 装反是常态

实际组装中电机很可能装反（左右轮出线方向相反），硬拆容易把齿轮弄坏。
**在代码里做方向修正**更稳妥。

config.h 里有三个开关：

```cpp
#define MOTOR_L_INVERT    0    // 左轮是否取反
#define MOTOR_R_INVERT    1    // 右轮是否取反
#define MOTOR_SWAP_LR     0    // 左右是否互换
```

### 调试顺序

```
1. 上电，串口发 MANUAL（停车，避免乱跑）
2. 发 FWD  → 两个轮子都往前？→ 不对就调 L_INVERT / R_INVERT
3. 发 BACK → 两个轮子都往后？→ 不对说明 invert 配错了
4. 发 LEFT → 原地左转（左轮反、右轮正）？
5. 发 RIGHT → 原地右转？
```

### 关键教训

**不要用"统一翻转 dir"来修后退方向。**

```cpp
// ❌ 错误：这样会绕过单侧的 R_INVERT，变成一侧往前一侧往后 → 原地打转
void backward(int speed) {
  int d = MOTOR_BACK_FLIP ? 1 : -1;
  driveSide(0, d, speed);
  driveSide(1, d, speed);
}

// ✅ 正确：让每侧各自走 driveSide，invert 只在该函数内部生效
void backward(int speed) {
  driveSide(0, -1, speed);
  driveSide(1, -1, speed);
}
```

## 三、动力调优

### 症状：吱吱响但轮子不动，手拨一下才转

**不是电机坏了，也不是焊接问题。**

```
5V 轨 → MX1508 压降 0.5V → 电机实际 4.5V
4.5V × 40% 占空比 = 等效 1.8V
TT 电机 1:48 减速箱静摩擦大，1.8V 带不动
```

手拨一下能转 = 外力帮忙突破静摩擦，**最容易误判成机械卡死**。

### 修法一：提高基础速度

```cpp
#define MOTOR_SPEED_CRUISE    80    // 40% 不够，实测 60% 起可用
#define MOTOR_SPEED_TURN      75
#define MOTOR_SPEED_SLOW      70    // 这个是下限
```

### 修法二：满力矩起步

```cpp
// 先 100% 冲 250ms 突破静摩擦，再降到目标速度
void forwardKick(int speed, int kickMs = 250) {
  driveSide(0, 1, 100);
  driveSide(1, 1, 100);
  delay(kickMs);
  forward(speed);
}
```

### 修法三：后退补偿

实测后退动力不如前进（电机两向碳刷磨损不一致）：

```cpp
#define MOTOR_BACK_BOOST     125    // 后退时占空比 ×1.25
```

### 修法四：MX1508 改接 9V（最有力，但要谨慎）

```
现在：9V → HW-131(5V) → MX1508 → 电机 4.5V
改成：9V ────────────→ MX1508 → 电机 8.5V
```

⚠️ 只有 MX1508 接 9V，**ESP32 仍然走 5V**。电机变快后要重新调速度参数。

## 四、调试命令

串口（115200）或网页调试面板都能发：

| 命令 | 作用 |
|---|---|
| MANUAL | 切手动 + 停车 |
| STOP | 立即停车 |
| FWD / BACK / LEFT / RIGHT | 四方向校准（各 1-2 秒） |
| L+80 / L-80 / R+80 / R-80 | 单轮测试，数字是占空比 |
| L0 / R0 / ALL0 | 停单轮 / 全停 |
| RAW+ / RAW- | 原始 GPIO，绕过所有方向修正（定位用） |

### RAW 命令的用途

如果 FWD 方向对但 BACK 不对，怀疑是逻辑问题，就用 RAW- 直接写引脚：

```cpp
analogWrite(PIN_MOTOR_L1, 0);    // 左轮反转
analogWrite(PIN_MOTOR_L2, 230);
analogWrite(PIN_MOTOR_R1, 230);  // 右轮反转
analogWrite(PIN_MOTOR_R2, 0);
```

**两侧都用 nalogWrite**，不要一侧 digitalWrite 一侧 nalogWrite——那样力矩不对称。

✗ 焊接不良 —— 单轮能转就不是
✗ 供电不足 —— 9V 电池 + 5V 稳压够用

## 六、⚠️ 最隐蔽的坑：动作之间会失效

### 现象

``````
单独测 FWD  → 正常
单独测 BACK → 正常
但连续测 FWD → BACK → LEFT → RIGHT
  → 后退和右转失灵（能前进、能左转，就是不动）
``````

**这个现象极易误判成电机坏了或代码逻辑错**，因为单测都正常。

### 根因

`stop()` 用 `digitalWrite(LOW)` 关引脚，但之前 `analogWrite` 设的
**PWM 占空比寄存器还留着旧值**。紧接着做反向动作时，MX1508 同时
收到冲突电平（一个引脚要 HIGH 一个要 0），表现为不动或抖动。

### 修法一：stop 时先清 PWM 寄存器

``````cpp
void stop() {
  // 先清占空比，再拉低。顺序不能反。
  analogWrite(PIN_MOTOR_L1, 0);
  analogWrite(PIN_MOTOR_L2, 0);
  analogWrite(PIN_MOTOR_R1, 0);
  analogWrite(PIN_MOTOR_R2, 0);
  // 再拉低保证确定状态
  digitalWrite(PIN_MOTOR_L1, LOW);
  digitalWrite(PIN_MOTOR_L2, LOW);
  digitalWrite(PIN_MOTOR_R1, LOW);
  digitalWrite(PIN_MOTOR_R2, LOW);
}
``````

### 修法二：动作之间留静默期

``````cpp
g_motor.stop();
Serial.println("[校准] 停");
delay(300);   // 让 MX1508 复位，否则下一个动作会失灵
``````

### 排查方法

如果遇到「某个方向单独能跑、连着跑就不行」：

``````
1. 单独测那个方向 → 正常？
2. 在它前面加一个别的动作 → 失效？
   → 就是 PWM 残留问题
3. 加 delay(300) 试 → 好了就确认
``````

**不要一上来就怀疑电机或接线。** 单测正常说明硬件没问题。

## 七、最终可用的配置

``````cpp
// config.h
#define MOTOR_SPEED_CRUISE    80      // 巡航
#define MOTOR_SPEED_TURN      75      // 转向
#define MOTOR_SPEED_SLOW      70      // 慢速下限
#define MOTOR_BACK_BOOST     100      // 后退补偿（100 = 不加成）
#define MOTOR_DEBUG            0      // 排查时改 1 看日志

#define MOTOR_L_INVERT         0      // 左轮方向修正
#define MOTOR_R_INVERT         1      // 右轮方向修正（装反了）
#define MOTOR_SWAP_LR          0      // 左右互换
``````

### 后退不要加 kick

``````cpp
void backwardKick(int speed, int kickMs = 250) {
  // ⚠️ 后退不能 kick
  // MOTOR_BACK_BOOST 已经让占空比顶到 100%，kick 再冲一次
  // 等于连续满功率启动两次，MX1508 会过流保护 → 吱吱响不动
  (void)kickMs;
  backward(speed);
}
``````
