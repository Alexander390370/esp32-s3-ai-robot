## 二、接线表

### 电源轨分配

```
上 + 轨 = 5V    → ESP32 VIN、MX1508 VCC、HC-SR04 VCC、MAX98357 VIN
上 − 轨 = GND   → 所有 GND
下 + 轨 = 3.3V  → OLED VCC、INMP441 VDD
```

**必须连的两条跳线：**

```
上 − 轨 ←——→ 下 − 轨   （两个 GND 要通）
上 + 轨左端 ←——→ 右端   （面包板长轨中间是断的）
```

### 信号线

| 模块 | 引脚 | → | ESP32-S3 |
|---|---|---|---|
| OLED | SDA / SCL | → | GPIO8 / GPIO9 |
| HC-SR04 | Trig / Echo | → | GPIO4 / GPIO5 |
| MX1508 | INT1 / INT2 / INT3 / INT4 | → | GPIO6 / 7 / 15 / 16 |
| INMP441 | SCK / WS / SD / L/R | → | GPIO17 / 18 / 21 / **GND** |
| MAX98357 | BCLK / LRC / DIN | → | GPIO41 / 42 / 40 |

### 三个容易接错的地方

**1. INMP441 的 L/R 必须接 GND**

悬空会输出左右声道交错的乱码，识别出来全是噪声。

**2. 喇叭两根线都不能接地**

MAX98357 是 BTL 桥接输出，任意一端接地会烧功放。

**3. DHCP 会改 PC 的 IP**

固件里 MQTT_HOST 要跟着改，或者用串口配网。

## 三、接线顺序

一次接一个，接完验证一个。

| 步 | 接什么 | 怎么验证 |
|---|---|---|
| 1 | 电源系统 | 万用表测 5V / 3.3V |
| 2 | ESP32 上电 | 红灯亮，串口 [0/5] PSRAM ... OK |
| 3 | OLED | [3/5] OLED 完成，屏幕出现眼睛 |
| 4 | 超声波 | [避障] 前方 Xcm，手晃数字变化 |
| 5 | MX1508 + 电机 | 轮子转（见 [电机调试](02-电机调试.md)） |
| 6 | INMP441 | [Audio] 麦克风就绪 |
| 7 | MAX98357 + 喇叭 | [Audio] 功放就绪 |

**每步都断电再接下一根线。**

## 四、超声波分压

HC-SR04 的 Echo 输出等于自己的供电电压。**3.3V 供电就不用分压**，直接接 GPIO5。

如果坚持用 5V 供电（量程更大），必须分压：

```
                 1kΩ                      1kΩ
HC-SR04 Echo ──/\/\/\──┬── ESP32 GPIO5 ──/\/\/\──┐
                       │                          │
                       └──────────────────────────┴── GND
```

5V × 1k/(1k+1k) = 2.5V，在安全范围（ESP32 高电平阈值约 2.0V）。

**实测 3.3V 供电的超声波工作正常**，量程约 2-150cm，对小机器人够用。

## 五、上电前检查

```
□ 万用表测 5V 轨 和 GND 轨：电阻 > 100Ω（0 就是短路）
□ 电容极性：长脚在 +，短脚（白条纹）在 −
□ OLED VCC 接的是 3V3，不是 5V
□ INMP441 VDD 接的是 3V3，不是 5V
□ 喇叭两根线都在绿色端子里，没有一根接地
□ 所有 GND 连通
□ 面包板上下电源轨已连通
```

**第一条最重要，测出 0 就断电重查。**
