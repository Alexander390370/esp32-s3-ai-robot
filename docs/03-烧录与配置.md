# 烧录与配置

> 第一次烧录会遇到几个"看起来像坏了"的坑，都在这里。

## 一、烧录

### 正常流程

```bash
cd firmware
cp src/config.example.h src/config.h    # 改 MQTT IP 和引脚
pio run -t upload --upload-port COM8
```

### 报 Write timeout 怎么办

S3 的 USB-Serial/JTAG 口在板子反复重启时，esptool 抓不到握手窗口。

```
1. 按住板子上的 BOOT 键
2. 点一下 RST
3. 松开 BOOT
4. powershell -ExecutionPolicy Bypass -File ..\flash.ps1
```

`flash.ps1` 用的是 `--before no_reset`，绕过自动复位。

### ⚠️ 串口一个字都没有

**这块 S3 有两个 USB 口，Serial 指向哪个由 `platformio.ini` 决定：**

| 插的口 | 出现的端口 | 必须的配置 |
|---|---|---|
| **UART 口**（CH343） | COM8 | `ARDUINO_USB_CDC_ON_BOOT=0` |
| **USB 口**（原生 JTAG） | COM10 | `ARDUINO_USB_CDC_ON_BOOT=1` |

配错的症状：**端口在、能烧录、但串口一个字都没有**。

### ⚠️ PSRAM 用不了（只剩 320KB 堆）

```ini
board_build.arduino.memory_type = qio_opi
```

N16R8 的 8MB PSRAM 是 **Octal (OPI)**，不是 QSPI。不写这行会报：

```
E psram: PSRAM ID read error: 0x00ffffff, PSRAM chip not found
```

写对了会看到：

```
[0/5] PSRAM: 总 8386279 字节, 空闲 8386035 字节 OK
```

### ⚠️ USB 供电不足

WiFi 发射瞬间电流从 50mA 跳到 250mA，USB 口可能撑不住：

```
Error  Unknown USB Device (Device Descriptor Request Failed)
```

解决：换主机后面的 USB 口，或者改用电池供电（USB 只留数据）。

## 二、WiFi 配网

固件不写死 WiFi。上电后串口监视器（115200）输入：

```
WIFI 你的WiFi名 你的密码
```

配好存进 NVS，下次自动连接。换网络就再输一次，**不用重新编译**。

清除：`RESET_WIFI`

## 三、关键配置

### `firmware/src/config.h`

```c
#define MQTT_HOST         "192.168.1.100"   // PC 的 IP，换网络要改
#define MQTT_PORT         1884
#define I2S_SAMPLE_RATE   16000             // 必须和 TTS 一致
#define AUDIO_RECORD_SECONDS 4
#define DANGER_DISTANCE_CM   20
#define OBSTACLE_AVOID_CM    30
```

### `pc/config.py`

```python
AI_BACKEND = "deepseek"        # deepseek / dashscope / ark / zhipu / stepfun / ollama
ASR_MODEL = "base"             # tiny / base / small / medium
TTS_ENGINE = "edge"            # edge（真人音质，需联网）/ sapi（本地，机械）
TTS_VOICE = "zh-CN-XiaoxiaoNeural"
TTS_RATE  = "+8%"
TTS_PITCH = "+2Hz"
TTS_SAMPLE_RATE = 16000        # 必须和固件 I2S_SAMPLE_RATE 一致
WEB_PORT = 8765                # 不能用 8080（Windows 保留端口）
```

## 五、串口命令

| 命令 | 作用 |
|---|---|
| `WIFI <ssid> <pass>` | 配 WiFi |
| `RESET_WIFI` | 清除 WiFi 配置 |
| `STATUS` | 打印传感器读数 |
| `REC` | 录音 4 秒并上传识别 |
| `CHAT` | 开关自动对话模式（VAD） |
| `RMS` | 查看 VAD 阈值和底噪 |
| `AUTO` / `MANUAL` | 自动避障 / 手动 |
| `STOP` | 立即停车 |
| `FWD` / `BACK` / `LEFT` / `RIGHT` | 方向校准 |
